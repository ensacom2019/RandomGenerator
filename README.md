# 🎲 RandomGenerator (랜덤 생성기)

현재 버전: **v1.3.0** · [변경 내역](CHANGELOG.md)

다양한 방식(룰렛, 사다리타기, 마블 핀볼, 추억의 뽑기판 추첨)으로 재미있게 결과를 뽑을 수 있는 반응형 웹 애플리케이션입니다.
별도의 백엔드나 빌드 과정 없이 순수 웹 표준(Vanilla JS, Canvas, CSS)으로 동작하며, 모든 데이터는 브라우저(`localStorage`)에 안전하게 자동 저장됩니다.

🔗 **라이브 웹사이트**: [https://ensacom2019.github.io/RandomGenerator/](https://ensacom2019.github.io/RandomGenerator/)

---

## 📑 주요 기능

### 1. 🎯 룰렛 돌리기 (Roulette)
- **자유로운 항목 및 비율 조절**: 항목 추가/삭제, 색상 선택, 가중치(`+`/`-`) 및 퍼센트(`%`) 수치 직접 입력 지원 (항상 100%로 자동 정규화)
- **항목 한번에 넣기**: 쉼표(`,`) 또는 줄바꿈(엔터)으로 항목 목록을 입력하면 모두 동일한 확률로 즉시 일괄 등록 (기존 항목 대체 또는 추가 지원)
- **항목 섞기**: 룰렛과 룰렛 다트에서 이름·색상·비율을 유지하며 순서만 무작위로 섞습니다. 회전 중에는 잠깁니다.
- **10개 프리셋 슬롯 저장/불러오기**: 자주 쓰는 룰렛 항목을 최대 10개 슬롯에 이름과 함께 저장하고 필요할 때 바로 불러오기 가능
- **회전 제어**: 시작, 자연스러운 감속 정지, 지정 위치로 바로 이동하는 즉시 정지 지원

### 2. 🎯 룰렛 다트 (Roulette Darts)
- **기존 룰렛과 같은 편집 화면**: 항목·색상·비율, 일괄 입력, 10개 프리셋 지원. 일반 룰렛과 설정을 따로 저장합니다.
- **다트 1~100개 설정**: 시작 후 판 안쪽을 클릭·터치하면 그 위치로, 스페이스바 또는 던지기 버튼을 누르면 위쪽 고정 조준점으로 던집니다.
- **비행과 명중 연출**: 다트가 0.36초 동안 궤적을 남기며 날아가고, 꽂힐 때 충격 파동과 짧은 떨림이 나타납니다. 꽂히는 순간의 항목을 기록한 뒤 판과 함께 회전합니다. 판 밖 클릭은 소모하지 않으며, 키를 꾹 눌러도 연속 발사되지 않습니다.
- **자동 감속과 결과**: 마지막 다트가 꽂히면 2.5~4.5초 동안 감속합니다. 정지 후 투척 순서와 항목별 명중 횟수를 표시하며, 같은 항목에 여러 번 맞을 수 있습니다.
- **탭 전환**: 다른 탭을 보는 동안 다트 진행을 일시 정지하고 돌아오면 이어갑니다.

### 3. 🪜 사다리타기 (Ladder)
- **칸에서 직접 입력**: 처음부터 위쪽 이름 칸과 아래쪽 결과 칸이 입력창으로 표시됩니다. 인원을 2~20명으로 정하고, 첫 칸에 쉼표로 여러 항목을 한 번에 입력할 수 있습니다. 부족한 결과는 꽝으로 채우며 참가자·결과 섞기도 지원합니다.
- **무작위 사다리**: 같은 높이에서 가로 연결선끼리 겹치지 않도록 생성하고, 모든 참가자를 서로 다른 결과 칸에 하나씩 연결합니다.
- **입력 → 시작 → 이름 선택**: `시작`을 누르면 입력을 마치고 사다리를 공개하며 타기가 활성화됩니다. 이후 이름을 눌러 개별 경로를 재생하거나 `전체 타기`로 진행합니다. 수정·다시 만들기는 다시 입력 단계로 돌아갑니다. 일시정지·속도 조절·결과 바로 보기도 지원합니다.
- **결과 숨기기·결과표**: 도착 전까지 결과를 숨기고, 도착 후 참가자별 결과를 표시합니다. 입력 설정은 브라우저에 저장합니다.
- **당첨자 강조**: 결과가 `꽝`·`당첨`으로만 구성된 경우에만 당첨자 이름에 🏆 표시를 붙이고 안내·경로·결과 칸·결과표를 강조합니다. 결과 바로 보기에도 적용하며, 다른 문구가 섞인 일반 배정에서는 당첨자 표시를 하지 않습니다.
- **모바일 지원**: 위아래 이름·결과 칸은 판 안에서 고정되고, 큰 사다리는 내부에서 스크롤되며 진행 중인 경로를 따라 화면이 이동합니다. 다른 탭에서는 진행을 멈추고 돌아오면 이어집니다.

### 4. 🎳 마블 핀볼 (Marble Race Pinball)
- **자체 2D 물리 엔진**: 충돌 반발력, 회전 바, 튕김 범퍼, 구슬 간 질량/충돌 처리가 적용된 리얼타임 마블 레이스
- **작은 원형 핀**: 모든 맵의 기본 원형 핀은 약하게 튕기는 범퍼로 동작합니다.
- **결승 직전 회전바**: 모든 맵에 양쪽 낙하 경로 2개, 그 아래 빈 공간 1개, 깔때기 경사면 양쪽 2개로 총 5개의 회전바를 배치했습니다. 떨어지거나 경사면을 타고 내려오는 구슬을 튕겨 마지막까지 순서가 달라질 수 있습니다. 좁은 결승 통로는 비워 둡니다.
- **5가지 다채로운 맵 지원**:
  1. `클래식 (밸런스)`: 약하게 튕기는 작은 범퍼 지대, 세 갈래로 갈라지고 다시 섞이는 두 분기 구간, 회전 막대, 큰 범퍼, 결승 깔때기가 배치된 맵. 짧은 경사와 가운데 직하 경로를 따라 구슬의 속도와 순서가 달라집니다.
  2. `핀 숲 (파칭코)`: 모든 원형 핀이 약하게 튕기는 작은 범퍼로 구성되어, 완충 선반 사이를 통통 튀며 내려가는 파칭코 스타일 맵
  3. `회전 지옥 (스피너)`: 다단 회전 막대와 범퍼가 연속 배치되어 역전이 자주 일어나는 맵
  4. `다단 깔때기 (슬라이드)`: 넓은 경사면과 좁은 깔때기 병목을 통과하며 치열한 몸싸움이 펼쳐지는 맵
  5. `익스트림 바운스 (카오스)`: 슈퍼 고탄성 범퍼, 초고속 듀얼 스피너, 벽면 반사 패드, 점프 런치 램프가 어우러져 구슬들이 폭죽처럼 튀고 날아다니는 익스트림 맵
- **유연한 구슬 입력 문법**:
  - `*숫자`: 해당 이름의 구슬 개수 (예: `철수*5, 영희*10`)
  - `/숫자`: 구슬의 질량 및 밀어내는 힘 (예: `대장/2, 막내/0.5`)
- **전원 완주 & 실시간 순위표**: 승리자(당첨 순위)가 나와도 경기가 멈추지 않고 마지막 구슬까지 레이스를 완주하며, 종료 시 1등부터 꼴찌까지의 **전체 순위표 모달** 제공
- **당첨 순위 지정**: 1등, 꼴찌, 특정 순위(#N) 또는 랜덤 순위를 자유롭게 지정 가능

### 5. 🎁 추첨판 뽑기 (Lottery Board)
- **추억의 별 스티커 뽑기판**: 최대 100칸까지 원하는 항목과 수량(예: `1등*1, 2등*2, 3등*3, 꽝*14`)을 설정하여 나만의 뽑기판 생성
- **뽑기 인터랙션**: 별(★) 스티커를 떼어내는 애니메이션 연출과 결과 확인 팝업
- **실시간 현황판**: 남은 칸 수, 항목별 남은 수량 현황, 뽑은 결과 히스토리를 한눈에 확인
- **안전 제한**: 100칸 초과 시 안내 경고 및 시작 차단으로 공정한 뽑기 환경 보장

### 6. 🎱 번호 뽑기 (Lotto Drum Machine)
- **자유로운 번호 범위 지정**: `0`부터 사용자가 원하는 끝 번호(예: `0~45`, `1~45`, `1~100` 등)까지 지정 가능
- **2가지 추첨 모드 지원**:
  1. `나온 번호 또 안 나오기 (중복 없음 / 비복원 추출)`: 이미 뽑힌 번호는 풀에서 제외되어 중복 없이 차례대로 추첨 (잔여 수량 실시간 카운트)
  2. `나온 번호 상관 없이 나오기 (중복 허용 / 복원 추출)`: 매 추첨마다 전체 번호 풀에서 무작위로 추출
- **로또 추첨기 3D 물리 연출**:
  - 투명 아크릴 챔버(구슬함) 내부에서 에어와 회전 날개로 역동적으로 텀블링하는 구슬들
  - 곡선 배출 튜브(아크릴 레일)를 타고 굴러나와 화면 앞으로 확대되는 스포트라이트 & 파티클 축하 효과
- **편의 기능**:
  - `1개 뽑기` 및 한 세트를 한 번에 추첨하는 `연속 6개 뽑기`
  - 표준 로또 컬러(노랑, 파랑, 빨강, 회색, 초록, 보라)가 적용된 3D 로또볼 결과 트레이
  - `번호순(오름차순) 정렬 토글` 및 당첨 번호 `클립보드 즉시 복사`

```text

│   └── lotto.css            # 로또 구슬함, 3D 로또볼, 결과 트레이 스타일
├── js/                      # 자바스크립트 모듈
│   ├── tabs.js              # 유연한 탭 전환 관리자 (TabManager)
│   ├── roulette.js          # 룰렛 물리 회전 및 10개 프리셋 로직
│   ├── ladder-engine.js     # 사다리 생성 및 일대일 경로 추적
│   ├── ladder.js            # 사다리타기 입력, 애니메이션, 결과 표시
│   ├── pinball-engine.js    # 독립 실행 가능한 핀볼 물리/충돌 연산 엔진
│   ├── pinball.js           # 핀볼 렌더링, 카메라 추적, 경기 진행 제어
│   ├── draw.js              # 추첨판 셔플, 클릭 인터랙션, 이력 관리
│   └── lotto.js             # 로또 구슬함 회전, 튜브 배출, 복원/비복원 추첨
├── index.html               # 메인 웹 페이지 (SPA)
└── README.md                # 프로젝트 문서
```

## 🛠️ 기술 스택 및 특징

- **Language & Runtime**: HTML5, CSS3, Modern JavaScript (ES6+)
- **Graphics**: HTML5 `<canvas>` API (고해상도 Retina/DPR 대응, 더블 버퍼링 렌더링)
- **Storage**: 브라우저 `localStorage` (룰렛 설정 및 프리셋, 핀볼 설정, 추첨 항목 보존)
- **Deployment**: GitHub Pages (정적 호스팅, No Build Tools Required)
- **Compatibility**: Chrome, Edge, Safari, Firefox 등 최신 웹 브라우저 및 모바일 반응형 지원

## 🚀 로컬 실행 방법

별도의 Node.js 패키지 설치나 빌드 과정 없이, 브라우저에서 `index.html` 파일을 바로 열면 실행됩니다.

## 검증

Node.js가 설치된 환경에서 외부 패키지 없이 엔진 테스트를 실행할 수 있습니다.

```sh
node tests/ladder-engine.test.cjs
node tests/pinball-finale.test.cjs
```
