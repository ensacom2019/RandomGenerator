# RandomGenerator

랜덤뽑기를 다양하게 지원하는 웹사이트입니다. (GitHub Pages)

🔗 https://ensacom2019.github.io/RandomGenerator/

## 기능

| 탭 | 설명 |
|----|------|
| **룰렛** | 항목을 추가하고 항목별 비율을 조절할 수 있는 룰렛. 시작 / 정지 / 즉시 정지 지원 |
| **핀볼** | 구슬이 맵을 굴러 내려가는 마블 레이스 핀볼. 4종 맵(클래식, 핀 숲, 회전 지옥, 다단 깔때기), 당첨 순위 지정, 전원 완주까지 실시간 레이스 및 전체 순위표 제공 |
| **추첨** | 항목과 개수를 정해 추첨판(최대 100칸)을 만들고, 칸을 눌러 숨겨진 항목 확인 |

## 구조

정적 사이트이며 빌드 과정이 없습니다. `index.html`을 브라우저로 열면 바로 동작합니다.

- `index.html` : 탭 구조 및 페이지
- `tabs.js` : 탭 관리자 (`TabManager.register()` 로 탭 추가)
- `roulette.*`, `pinball*.js/css`, `draw.*` : 각 탭 구현

설정(항목 등)은 브라우저 `localStorage`에 저장됩니다.
